# 🥗 AI-Powered Nutrition & Diet Planner

## 📌 Overview

The **AI-Powered Nutrition & Diet Planner** is a web-based application that provides personalized diet recommendations based on user health data. It uses Machine Learning to analyze user inputs such as age, weight, height, activity level, and fitness goals to generate intelligent meal plans.

---

## 🚀 Features

* 🔐 User Authentication (Register/Login)
* 📊 BMI & BMR Calculation
* 🤖 AI Chatbot for Diet Advice
* 🍽 Personalized Meal Plans
* ✅ Input Validation (Frontend + Backend)
* 💾 SQLite Database Integration
* 🎨 Responsive UI using Bootstrap

---

## 🧠 How It Works

1. User registers and logs into the system
2. Inputs health details:

   * Age
   * Weight
   * Height
   * Gender
   * Activity Level
   * Fitness Goal
3. System calculates:

   * BMR (Basal Metabolic Rate)
   * BMI (Body Mass Index)
   * Daily Calorie Needs
4. Personalized meal plan is displayed with visualization
